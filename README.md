# 幸福双翼教育AI学习教练

**陪孩子想明白，帮家长陪得更从容 · v1.1.0**

从喜欢的称呼开始，结合真实试卷和练习，一次聊一点、一起想一步。家长不用先读长报告，就能知道今天怎样陪着学。

📖 **[打开家长使用手册](使用手册.md)**：如何开始、怎么发作业、怎样一起定目标，以及下次怎么接着学，都有可复制的话。

## 在自己常用的AI工具里开始

这是一套学习教练的工作说明，也可作为技能（Skill）使用。不同工具支持的方式不同：能安装技能的，按它的说明安装；能设置专属助手的，放入教练说明和参考资料；只能聊天的，也可以上传或粘贴说明，作为本次对话的约定。具体操作见[使用手册](使用手册.md)。

如果工具支持从项目链接安装技能，可以把下面这段话发给它：

```text
请帮我安装个性化AI学习教练。
项目地址：https://github.com/Eveline160919103/AI-
技能文件夹：child-learning-coach
安装后请检查技能文件是否完整，并告诉我是否已安装成功。
```

准备好教练说明后，说：

```text
请做我们的个性化AI学习教练，先认识一下孩子，再和我商量学习目标。
```

教练会先问：“你希望学习教练之后怎么称呼孩子呢？”随后慢慢了解年级、教材、学科、学习表现和近期愿望，也会主动邀请你提供方便拿到的试卷、错题或练习册，不必一次准备齐全。

## 它会怎样陪你们

- 把题目和原作答看准，请你对照确认后再分析。
- 帮你把“想学好、想提高”细化成孩子能做到的小目标。
- 一次只问一个问题，让孩子自己想、自己试、讲讲为什么。
- 主动准备周月安排，平时只说当前的小任务；想看完整计划时，再展开给你。
- 拿到完整试卷后，邀请你选择知识小卡片、配合近期课堂学习，或清楚好看的知识地图。
- 为每个孩子保留自己的小档案，逐渐找到更合适的讲法与练法。

小学低、中、高年级及初高中会采用不同的表达和引导方式。知识地图少而清楚，只画目前有材料支持的内容，后续再补充；没见到相关练习，不等于孩子不会。

## 一起守住的约定

以孩子的年级和学校已学内容为准，不代写作业，不承诺提分，也不因为一次错题给孩子下结论。真实试卷和小档案留在家长自己的学习空间，不上传到这个公开项目。

能否识别图片、安装技能或保存记录，取决于你使用的工具。教练会说明实际能做到什么；换对话或换软件时，带上小档案，就更容易接着学。
